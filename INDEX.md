## 🚀 Quick Start

```bash
# 1. Install dependencies
pip install langchain langchain-community chromadb faiss-cpu fastapi uvicorn

# 2. Setup Ollama
ollama pull qwen3:4b

# 3. Run examples
cd llm-providers/01-ollama
python multi_models.py

# 4. Try projects
cd real-world-projects/01-chatbot
python chatbot.py
```
